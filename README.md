# STK-NODE-NEST-RESTAPI-MONGODB-MONGOOSE

---

## Stack

- `node.js`
- `nest.js`
- `rest-api`
- `mongodb`
- `mongoose`
- `typescript`

---

## Run - Dev

`make env file: .env.dev`

```
npm i
```

```
docker compose -f ./compose.db.yaml --env-file ./.env.dev up --build -d
```

```
npm run start:dev
```
